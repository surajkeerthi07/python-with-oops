# python-with-oops
# Python with OOPs

This repository contains the Python programs I've been practicing , learning and working on

I've covered different OOP concepts, exception handling and basic data structures. I'm uploading these programs here to keep track of what I've learnt and to have my practice code organised in one place.

### 01. OOP Basics
- Classes and Objects
- Constructors
- Multiple Methods
- Multiple Objects
- Area and Volume of a Rectangle

### 02. Inheritance
- Single Inheritance
- Inheritance with Attributes and Methods
- Multilevel Inheritance
- Multiple Inheritance
- Hierarchical Inheritance

### 03. Polymorphism
- Method Overriding
- Operator Polymorphism
- Runtime Polymorphism
- Function Polymorphism
- Polymorphism Using Different Classes

### 04. Encapsulation & Abstraction
- Encapsulation
- Access Modifiers
- Getter and Setter Methods
- Arithmetic Operations Using Classes
- Bank Account Class
- Abstraction Using ABC

### 05. Exception Handling
- Try Block
- Multiple Exceptions
- Try-Else Block
- Finally Block

### 06. Linked Lists
- Singly Linked List
- Insertion at the Beginning
- Insertion at the End
- Insertion at a Specific Position
- Doubly Linked List

## Requirements
- Python 3

## Running the Programs

You can download or clone this repository and run the programs individually.

```bash
git clone https://github.com/surajkeerthi07/python-with-oops.git
```

Navigate to the folder containing the program and run:

```bash
python filename.py
```
